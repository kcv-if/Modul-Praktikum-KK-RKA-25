# Probability dan Uncertainty

Kerjakan notebook berikut secara berurutan:

1. [Probability Distribution](01%20-%20Probability%20Distribution.ipynb): distribusi peluang, joint, conditional probability, aturan Bayes, dan inferensi dari tabel joint.
2. [Bayesian Network](02%20-%20Bayesian%20Network.ipynb): graf dan CPT, faktorisasi joint, independensi bersyarat, enumeration, variable elimination, dan sampling.

Buka notebook di Jupyter atau Google Colab. Jalankan sel **Setup** terlebih dahulu, kemudian jalankan sel berikutnya secara berurutan. Setup akan memasang paket yang diperlukan jika belum tersedia.

Notebook Bayesian Network menggunakan contoh alarm rumah dan penyiram rumput. Setiap bagian memuat penjelasan konsep, contoh kode, dan penafsiran hasil perhitungan. Referensi bacaan tersedia sebelum bagian latihan.

Lima latihan pada akhir notebook mencakup perhitungan joint, penggunaan evidence, pembuatan jaringan, eliminasi variabel, dan percobaan sampling. Tuliskan jawaban pada sel yang tersedia dengan penjelasan, perhitungan, atau kode sesuai kebutuhan soal. Petunjuk dapat dibuka di bawah setiap soal.

Jika menggunakan kode dalam jawaban, pastikan kode tersebut dapat dijalankan.
